# Datenschutzerklärung für Openclaw

Stand: November 2026

Openclaw ist ein privates Werkzeug, das ausschließlich vom Betreiber genutzt wird, um Videos auf seine eigenen YouTube-Kanäle hochzuladen und zu verwalten.

## Welche Daten verwendet werden

Openclaw greift über die YouTube Data API mit Zustimmung des Kontoinhabers auf dessen eigene YouTube-Kanäle zu. Die dabei erhaltenen Zugriffstoken werden nur lokal auf dem Computer des Betreibers gespeichert.

## Weitergabe

Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung verwendet. Es werden keine Daten anderer Nutzer erhoben.

## Nutzung von Google-Daten

Die Nutzung der von Google-APIs erhaltenen Informationen entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

## Widerruf

Der Zugriff kann jederzeit unter https://myaccount.google.com/permissions widerrufen werden.
